# CS2 Callout Trainer

Cette archive contient une version autonome du quiz : ouvrez `index.html` pour l'utiliser localement, ou déposez son contenu sur un hébergeur statique.

## Publication gratuite avec GitHub Pages

1. Créez un compte GitHub, puis un nouveau dépôt public, par exemple `cs2-callout-trainer`.
2. Décompressez cette archive et importez **tous les fichiers**, en conservant le dossier `assets`.
3. Dans le dépôt, ouvrez **Settings > Pages**.
4. Dans **Build and deployment**, choisissez **Deploy from a branch**, puis sélectionnez la branche `main` et le dossier `/ (root)`.
5. Enregistrez : GitHub fournit un lien public à partager.

## Publication gratuite avec Cloudflare Pages

1. Créez un compte Cloudflare et ouvrez **Workers & Pages > Create > Pages**.
2. Choisissez **Upload assets**.
3. Décompressez l'archive, puis déposez le dossier contenant `index.html` et `assets`.
4. Cloudflare fournit un lien public à partager.

## Important

Les cartes et les progrès ajoutés depuis l'éditeur sont enregistrés localement dans le navigateur de chaque joueur. Ils ne sont donc pas partagés automatiquement entre les joueurs.
